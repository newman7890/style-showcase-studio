# Cynt Fashion E-Commerce Studio

A modern fashion e-commerce application built with React, TypeScript, Vite, Tailwind CSS, shadcn-ui, and Supabase.

## Getting Started

### Requirements
- Node.js & npm (or Bun)

### Local Development Setup

1. **Install Dependencies:**
   ```sh
   npm install
   ```

2. **Set up Environment Variables:**
   Ensure your `.env` contains your Supabase project credentials:
   ```env
   VITE_SUPABASE_PROJECT_ID="wnfmcdncbbfcyfoewewd"
   VITE_SUPABASE_URL="https://wnfmcdncbbfcyfoewewd.supabase.co"
   VITE_SUPABASE_PUBLISHABLE_KEY="your_anon_key"
   ```

3. **Start Development Server:**
   ```sh
   npm run dev
   ```

## Technologies Used

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui, Framer Motion
- **Backend:** Supabase (PostgreSQL, Auth, Edge Functions, Storage)
